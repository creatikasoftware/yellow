# Yellow Achiever's Award — Multi-Page Bootstrap Prototype

## Structure
- index.html — Home
- about.html — About
- events/index.html — Events listing
- events/event-detail.html — Event detail
- awards/index.html — Award categories
- awards/award-detail.html — Award category detail
- speakers/index.html — Speakers
- speakers/speaker-detail.html — Speaker detail
- gallery/index.html — Gallery
- news/index.html — News listing
- news/news-detail.html — News detail
- contact.html — Contact
- registration.html — Registration
- assets/css/style.css — Shared stylesheet
- assets/js/main.js — Shared JavaScript
- assets/images/ — Logo and future images

This is a static frontend prototype. It is structured so the PHP/MySQL CMS can later replace the hard-coded content with database-driven data.
